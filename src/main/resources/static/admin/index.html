使用说明

1. 管理员先上传 Excel 花名册，系统会自动建立班级、学生和班主任账号。
2. 班级打卡链接格式为 `/checkin.html?code=班级特征码`。
3. 导出支持按日、周、月生成 Excel，班主任账号会自动限制为本班数据。
4. 战力榜可按日期和时段查询，默认查询当天早上时段。

修改我的密码

默认密码统一为 `dlzx`。首次登录后必须先修改密码，修改成功后系统会自动刷新登录状态。
建议使用不低于 4 位的新密码。

学生花名册上传

学生模板仅包含：年级、班号、学号、学生姓名。班号只填数字，例如 `1` 会自动识别为 `1班`。
等待上传学生花名册。

角色支持中文或英文：`班主任 / 级长 / 行政`，或 `TEACHER / GRADE_LEADER / STAFF`。班号只填数字即可。
等待上传教职工账号表。
